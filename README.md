# Catalogador de inventario hospitalario · versión 3.1

Aplicación de escritorio (Java 11+, sin librerías externas) para relacionar cada equipo del inventario de un hospital con su nombre oficial en los catálogos GMDN y de Mantenimiento, en modo manual o con ayuda de una IA (ChatGPT, Gemini, Claude, Groq… u Ollama en local).
